# BUG-07: Хайлтын үед том, жижиг үсгийг ялгаж байна

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Windows 11

**Урьдчилсан нөхцөл:** node app.js ажиллаж, "The Pragmatic Programmer" ном жагсаалтад байна.

## Дахин гаргах алхам
1. http://localhost:3000 хаягийг нээнэ.
2. Хайлтын талбарт the гэж жижиг үсгээр бичнэ.
3. "Хайх" товчийг дарна.
4. Хайлтын үр дүнг шалгана.

**Хүлээгдэж байсан:** Том, жижиг үсэг үл харгалзан "The Pragmatic Programmer" ном олдоно.

**Бодит үр дүн:** Хүснэгтэд тохирох ном харагдахгүй, харин хайлтын үр дүн хоосон байна.

**Ноцтой байдал:** Minor - хайлтын хэрэглээний боломж хязгаарлагдаж байна.

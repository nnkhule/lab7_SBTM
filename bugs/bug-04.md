# BUG-04: Тоон бус он оруулахад NaN утга хүснэгтэд нэмэгдэж байна

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Windows 11

**Урьдчилсан нөхцөл:** node app.js ажиллаж, анхны 3 ном харагдаж байна.

## Дахин гаргах алхам
1. Он талбарт "dfd" гэж бичнэ.
2. Гарчиг болон зохиолчийн талбарыг хоосон үлдээнэ.
3. "Нэмэх" товчийг дарна.

**Хүлээгдэж байсан:** Тоон бус он болон шаардлагатай хоосон талбаруудыг зөвшөөрөхгүй.

**Бодит үр дүн:** Хүснэгтэд хоосон гарчиг, зохиолчтой мөр нэмэгдэж, он баганад NaN гэж харагдсан.

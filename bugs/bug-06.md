# BUG-06: Хайлт хийхэд "Ном нэмэгдлээ" гэсэн буруу мэдэгдэл гарч байна

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Windows 11

**Урьдчилсан нөхцөл:** node app.js ажиллаж, http://localhost:3000 хуудас нээгдсэн байна.

## Дахин гаргах алхам
1. Хөтөчөөр http://localhost:3000 хаягийг нээнэ.
2. Хайлтын талбарт zz гэж бичнэ.
3. "Хайх" товчийг дарна.
4. Хүснэгт болон мэдэгдлийн хэсгийг шалгана.

**Хүлээгдэж байсан:** Хайлтын үр дүн байхгүй бол "Илэрц олдсонгүй" эсвэл тохирох мэдээлэл харагдах ёстой.

**Бодит үр дүн:** Хүснэгтэд номын мөр харагдахгүй боловч "Ном нэмэгдлээ" гэсэн мэдэгдэл гарсан.

**Ноцтой байдал:** Minor - хэрэглэгчийг төөрөгдүүлсэн мэдэгдэл харуулж байна.

# BUG-10: Номын мэдээлэлгүй POST хүсэлт амжилттай болсон

**Орчин:** Уншлагын жагсаалт v2.0, Node.js API, Windows 11

**Урьдчилсан нөхцөл:** node app.js ажиллаж байна.

## Дахин гаргах алхам
1. CMD нээнэ.
2. curl.exe -i -X POST http://localhost:3000/api/books командыг ажиллуулна.
3. HTTP хариу болон JSON өгөгдлийг шалгана.

**Хүлээгдэж байсан:** Хэрэв API номын гарчиг, зохиолч зэрэг талбарыг заавал шаарддаг бол мэдээлэлгүй хүсэлтийг татгалзаж, 400 эсвэл 422 алдаа буцаана.

**Бодит үр дүн:** HTTP 201 Created, {"result":"OK","id":7} гэсэн хариу буцсан.

**Ноцтой байдал:** Major - шаардлагатай мэдээлэлгүй хүсэлтээр нөөц үүсгэж байвал.

# BUG-09: Ном устгах үед "Ном нэмэгдлээ" гэсэн буруу мэдэгдэл гарч байна

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Windows 11

**Урьдчилсан нөхцөл:** node app.js ажиллаж, номын жагсаалтад хэд хэдэн ном байна.

## Дахин гаргах алхам
1. http://localhost:3000 хаягийг нээнэ.
2. Жагсаалтаас дурын номын "Устгах" товчийг дарна.
3. Дэлгэц дээр гарч ирэх мэдэгдлийг ажиглана.

**Хүлээгдэж байсан:** Ном устгагдсан тухай "Ном устгагдлаа" гэсэн мэдэгдэл гарна.

**Бодит үр дүн:** Ном устгах үйлдэл хийсэн боловч "Ном нэмэгдлээ" гэсэн мэдэгдэл гарч байна.

**Ноцтой байдал:** Minor - хэрэглэгчид үйлдлийн талаар буруу мэдээлэл өгч байна.

# BUG-01: Хоосон талбартай ном нэмэгдэж байна

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Windows 11

**Урьдчилсан нөхцөл:** node app.js ажиллаж, анхны 3 ном харагдаж байна.

## Дахин гаргах алхам
1. http://localhost:3000 хаягийг нээнэ.
2. Гарчиг, зохиолч, он талбаруудыг хоосон үлдээнэ.
3. "Нэмэх" товчийг дарна.

**Хүлээгдэж байсан:** Хоосон мэдээлэлтэй ном нэмэгдэхгүй.

**Бодит үр дүн:** Хүснэгтэд хоосон мөр нэмэгдэж, он 0 гэж харагдсан.

**Ноцтой байдал:** Major

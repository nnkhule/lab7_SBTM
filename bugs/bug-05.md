# BUG-05: Хуучин хувилбарын хуудас Internal Server Error алдаа өгч байна

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Windows 11, Node.js

**Урьдчилсан нөхцөл:** node app.js ажиллаж, http://localhost:3000 хуудас нээгдэж байна.

## Дахин гаргах алхам
1. http://localhost:3000 хаягийг нээнэ.
2. Хуудасны доод хэсгийн "Хуучин хувилбар" холбоос дээр дарна.
3. Хөтөч http://localhost:3000/old хаяг руу шилжсэнийг шалгана.
4. Гарч ирсэн хуудасны алдааг ажиглана.

**Хүлээгдэж байсан:** Хуучин хувилбарын хуудас хэвийн нээгдэж, уншлагын жагсаалт харагдана.

**Бодит үр дүн:** /old хаяг дээр "Internal Server Error" гэсэн алдаа гарч, хуудас нээгдээгүй.

**Ноцтой байдал:** Major - хуучин хувилбарын хуудас ашиглах боломжгүй байна.

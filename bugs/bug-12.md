# BUG-12: HTML тусгай тэмдэгтүүд буруу харагдана

**Орчин:** Уншлагын жагсаалт v2.0, Windows 11, Google Chrome, localhost:3000

**Урьдчилсан нөхцөл:** `node app.js` ажиллаж байна.

## Дахин гаргах алхам

1. Хөтөчөөр http://localhost:3000 хаягийг нээнэ.
2. Гарчиг талбарт `<>` гэж оруулна.
3. Зохиогч талбарт `<>` гэж оруулна.
4. «Нэмэх» товчийг дарна.
5. Хүснэгтэд үүссэн мөрийг шалгана.

**Хүлээгдэж байсан:** Тусгай тэмдэгтүүдийг зөв харуулах эсвэл буруу өгөгдлийг ойлгомжтой алдааны мэдэгдлээр татгалзах.

**Бодит үр дүн:** Хүснэгтэд `&lt;&gt;` гэсэн тэмдэгтүүд шууд харагдаж байна.

# BUG-11: Байхгүй номыг устгахад амжилттай гэсэн хариу буцаана

**Орчин:** Уншлагын жагсаалт v2.0, Node.js API, Windows 11, curl.exe

**Урьдчилсан нөхцөл:** node app.js ажиллаж байна. ID 999-тай ном байхгүй.

## Дахин гаргах алхам
1. CMD нээнэ.
2. `curl -i -X DELETE http://localhost:3000/api/books/999` командыг ажиллуулна.
3. HTTP хариу болон JSON өгөгдлийг шалгана.

**Хүлээгдэж байсан:** Байхгүй ID-тай номыг устгах үед 404 Not Found хариу буцаах.

**Бодит үр дүн:** HTTP 200 OK, `{"result":"OK"}` гэсэн хариу буцсан.

**Ноцтой байдал:** Minor - байхгүй нөөцийг устгах үед буруу амжилтын төлөв мэдээлж байна.

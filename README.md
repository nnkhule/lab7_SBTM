# Lab07 — Exploratory Testing (SBTM)

# B232270018 Б. Энхбаяр

## 1. Төслийн тухай

Энэхүү лабораторийн ажлаар Уншлагын жагсаалт веб аппликейшнд Session-Based Test Management (SBTM) аргаар туршилт хийж, хэрэглэгчийн интерфейс болон API түвшний согогуудыг илрүүлэв.

## 2. Орчин

- Үйлдлийн систем: Windows 11
- Хөтөч: Google Chrome
- Сервер: Node.js (`app.js`)
- Хаяг: http://localhost:3000
- API шалгалт: `curl.exe`
- Хувилбарын удирдлага: Git

## 3. Charter

- **Судлах:** Ном нэмэх, хайх, устгах болон API үйлдлүүд.
- **Ашиглах:** Хоосон оролт, буруу өгөгдөл, том/жижиг үсгээр хайх болон API хүсэлтүүд.
- **Илрүүлэх:** Оролтын баталгаажуулалт, хайлт, өгөгдлийн бүрэн бүтэн байдал, алдааны мессеж болон API хариултын согогууд.

### Сонгосон аялалууд

1. **Supermodel (GUI):** Хуудасны талбар, товч, мессеж болон хүснэгтийг шалгах.
2. **Couch Potato:** Хоосон болон дутуу оролтоор баталгаажуулалтыг шалгах.
3. **Saboteur:** Буруу өгөгдөлтэй API хүсэлт илгээж шалгах.
4. **Fed-Ex:** Ном нэмэх, хайх, устгах үед өгөгдөл зөв дамжиж байгаа эсэхийг шалгах.

## 4. Туршилтын үр дүн

Туршилтын явцад дараах боломжит согогуудыг ажиглаж, тайлан бэлтгэв.

- Буруу хайлт хийхэд амжилтын мэдэгдэл гарч байгааг шалгасан.
- Гарчиг, зохиогчийн талбарт буруу утга оруулахад үүссэн үр дүнг шалгасан.
- HTML тусгай тэмдэгтүүдийг харуулах байдлыг шалгасан.
- Байхгүй ID-тай ном устгах API хүсэлтийн хариуг шалгасан.
- `/old` хуучин хувилбарын хуудас Internal Server Error буцаасныг тэмдэглэсэн.

Согог тус бүрийн дэлгэрэнгүй мэдээллийг `bugs/` хавтаснаас үзнэ үү.

## 6. Ажиллуулах заавар

1. Төслийн хавтас руу орно.
2. Терминалд дараах командыг ажиллуулна.

```cmd
node app.js
```

3. Хөтөчөөр http://localhost:3000 хаягийг нээнэ.
4. Туршилтын алхмуудыг гүйцэтгэж, үр дүнг `session-report.md` файлд тэмдэглэнэ.

## 7. Нотолгоо

- `bugs/` — согогийн дэлгэрэнгүй тайлангууд.
- `evidence/` — API хүсэлтүүдийн бүтэн гаралт хадгалсан текст файлууд.
- `screenshots/` — хэрэглэгчийн интерфейсийн дэлгэцийн зургууд.
- `session-report.md` — туршилтын явц, ажиглалт болон зарцуулсан хугацаа.

## 8. Дүгнэлт

Уншлагын жагсаалт веб аппликейшнийг GUI болон API түвшинд туршиж, илэрсэн асуудлуудыг баримтжуулав. Туршилтын үр дүнг согогийн тайлан, дэлгэцийн зураг болон API нотолгоогоор баталгаажуулсан.
